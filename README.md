Tic-Tac-Toe 🎮
A simple two-player Tic-Tac-Toe game that runs in the console, written in Java. 

How to play 🕹️
Two players take turns entering their moves. Player X always goes first.
On each turn, enter the row and column where you want to place your mark:
Row: 0, 1, or 2 (top to bottom)
Column: 0, 1, or 2 (left to right)

The first player to get three marks in a row (horizontally, vertically, or diagonally) wins. If the board fills up with no winner, the game ends in a draw.
After each game you will be asked if you want to play again 🔄.
